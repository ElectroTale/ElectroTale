Commandes en jeu

À taper dans la zone de texte, peu importe le mode :
/inv + corde ajoute un objet · /inv - corde l'enlève
/stat Force +1 · /stat Force -2 · /stat Force =3
/rel Kaya (renarde) — amie ajoute une relation
/pv -3 · /pv +5 · /pv =20 · /or +10
/quete Retrouver le collier — volé par un renard · /quete fini collier
/lieu Horgor change le lieu actuel
/dc 15 change la difficulté · /jet lance un d20 · /jet Agilité
/aide rappelle les commandes

🎲 d20 pour les actions risquées (la caractéristique est choisie selon l'action : Force, Agilité, Esprit, Charisme) · 💯 d100 pour la chance pure (parier, tenter sa chance, prier…) · 🩸 d4/d8 de blessure quand une action physique rate. Le Conteur raconte selon le résultat. La difficulté se règle dans la fiche du personnage ; ajoute une caractéristique « Chance » pour modifier les jets de chance (+5 % par point).

Bouton ⚔ en bas pour lancer un combat toi-même. Commandes : /combat Loup noir 3 (force 1 à 5) · /epreuve Agilité 14 traverser le pont · /potion · /fin arrête le combat.

Commande libre : /jet d20 · /jet d100 · /jet 2d6 · /jet d20 Agilité

Comment écrire un format ?

{texte} ce que tu tapes, avec majuscule et point
{TEXTE} pareil, EN MAJUSCULES
{action} ce que tu tapes, en minuscule sans point final
{brut} exactement ce que tu tapes
{nom} le nom du perso · {sujet} Kriil / Je / Tu
{dit} « Kriil dit » / « Je dis » / « Tu dis » (+ verbe auto)
{v:pense} verbe en -er conjugué tout seul (pense / penses)
{v:entend|entends|entends} verbe irrégulier : 3e|1re|2e
{v:s'approche} les pronominaux marchent aussi (m'approche, t'approches)
{jet} lance un d20 avec la carac choisie
{sujet} {action} ensemble : gère « J'ouvre », « Tu ouvres »…

Exemples : {sujet} {v:murmure} à l'oreille de quelqu'un : « {texte} » · *{nom} {action}.* · [Note du joueur : {texte}]

Les mots interdits utilisent l'option banned_tokens de KoboldCpp (versions récentes).

Voix

Kokoro : une voix de synthèse moderne et naturelle qui tourne sur ton PC (voix française « Siwis »). Sinon, les voix françaises de Windows marchent aussi. Pour en ajouter : Paramètres Windows → Heure et langue → Voix → Ajouter des voix (« Microsoft Hortense », « Julie », « Paul »…).

Tout est sauvegardé automatiquement. Exporte de temps en temps pour avoir une copie de secours.

Raccourcis : Entrée = envoyer · Maj+Entrée = retour à la ligne · Ctrl+1…9 = changer de mode · Tab dans la zone vide = mode suivant. Clique sur n'importe quel passage de l'histoire pour le modifier (vide-le pour le supprimer).

    Partager

    Un fichier « monde » ne contient pas l'histoire en cours : parfait pour réutiliser un monde ou le donner à quelqu'un.

    Une entrée du Codex est envoyée au Conteur quand un de ses déclencheurs apparaît dans les derniers paragraphes ( caractères). Le point vert = active en ce moment.

    Importe une image de ta carte (dessinée à la main, scannée, faite dans Inkarnate/Wonderdraft…), puis place tes lieux dessus.

    Glisse une épingle pour la déplacer. « 🧭 … est ici » change le lieu actuel : sa carte est envoyée à l'IA à chaque tour.

    Comme les scripts d'AI Dungeon : du JavaScript qui s'exécute à chaque tour. Le script Entrée reçoit l'action du joueur, Contexte reçoit tout ce qui va être envoyé à l'IA, Sortie reçoit la réponse de l'IA. La variable text contient le texte ; fais return du texte modifié (ou rien pour ne pas le changer). Les scripts font partie du monde (exportés avec lui).

    Ce que les scripts peuvent utiliser

    s objet libre sauvegardé avec l'aventure (ex : s.jour = 3)
    hero.name · hero.hp · hero.maxHp · hero.gold · hero.location · hero.inventory (modifiables, sauf name/inventory)
    info.turn nombre d'actions du joueur · info.mode mode utilisé
    msg("texte") petite notification · log(x) écrit dans la console ci-dessous · stop() bloque l'action (script Entrée)
    roll(20) lance un dé · stat("Force") · setStat("Force", 3)
    hasItem("corde") · addItem("corde") · removeItem("corde")
    damage(3) · heal(5) · addQuest("Titre", "détails") · completeQuest("Titre") · hasQuest("Titre")
    card("Shiva") contenu d'une carte · setCard("Shiva", "texte", "Personnage")
    getMemory() / setMemory(t) · getNote() / setNote(t) · lastOutput()

    
      
    ⚠ Les scripts ont accès à toute la page : n'en colle pas venant de quelqu'un en qui tu n'as pas confiance.
